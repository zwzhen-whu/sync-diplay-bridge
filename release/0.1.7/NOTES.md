CarPlay 仪表桥接 0.1.7，versionCode 8。

- 音乐按首次有效歌曲快照推送一次，之后只发送切歌或播放状态的实际变化，取消全部周期重发和启动清空/回填，避免仪表反复跳动。
- 新增默认关闭的自动进入 CarPlay 功能，需要使用情况访问授权。从真正连接成功开始观察 30 秒，入口页稳定约 2 秒后最多补跳一次。首次出现 CarPlay 后仍保留观察窗口，处理开机连接中途又退回 DiPlay 入口的情形。
- 首次前台查询覆盖本次开机，后续增量保留最新状态，避免主页停留很久后无法识别。切到其他应用、已补跳转或窗口结束后不持续拉回。
- DiPlay 的入口和设置共用 Activity；若连接后要停留在设置，请关闭自动进入。Android 10+ 的后台启动限制可能影响此辅助功能。
- 保留原签名、深色界面、路名回退、自启动及 5 秒导航超时，不修改 DiPlay APK。

自动进入可通过系统“使用情况访问”授权；没有授权页面的车机可在停稳后执行：

```sh
adb shell appops set com.local.diplay.clusterbridge GET_USAGE_STATS allow
```

构建、协议/导航/首次连接回归、签名检查已通过。现车完成覆盖安装与长时间入口停留的自动跳转验证；捕获到的首次开机退回时序已纳入回归。约 94 秒实车观察中，两首不同歌曲各推送一次，没有重复歌曲状态或空标题回填。0.1.7 的完整首次冷开机流程尚未再次实测。
