# 2.0 捐赠入口

版本号 2.0，版本代码 24，包名与原签名不变，可覆盖更新1.3并保留设置。

页面第一行将应用标题与捐赠按钮并排显示，按钮位于右侧，文本为“对您有帮助？给作者加鸡腿”。点击后显示用户提供的微信收款码原图，可点“关闭”、系统返回或弹窗外区域退出。

图片作为 `res/drawable-nodpi/donation_wechat.jpg` 随APK离线打包，保持比例完整显示，不裁切、不重绘二维码，不启动微信或自动发起支付。界面只显示图片，不增加权限、网络请求或支付接口。

已有导航、歌曲、通话、按键、蓝牙和诊断功能继续沿用1.3实现。本轮仅修改主页面展示、加入图片资源并提升版本号；构建沿用原签名，检查APK内图片字节与原图一致，并运行现有完整回归。

本轮未安装到车机；弹窗在目标车机上的布局与实际扫码仍待安装后核对。先前1.3的实车手动诊断记录不作为2.0新增界面已验证的证据。
