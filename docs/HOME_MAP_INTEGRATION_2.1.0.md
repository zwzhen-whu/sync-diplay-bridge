# 桌面地图集成 2.1.0

独立浮窗 0.2.6 的显示、拖动、圆角、渐变、外观设置和后台地图解码现已放入桥接插件的 homemap 模块。主界面顶部提供入口，无需同时运行两个应用。

## 迁移

1. 使用原证书更新桥接，保留 bridge 偏好和小组件绑定。
2. 打开桌面地图设置；通过车机既有本地接口读取同证书旧应用的白名单字段。
3. 点击接管：停用旧独立应用，保存 home_map 偏好。旧 APK 和数据不删除。
4. 若旧解码脚本驻留在 DiPlay，则先停止 DiPlay，创建由桥接 UID 拥有的 1280×480 虚拟显示，再打开 DiPlay 一次。
5. 新运行时校验所属包、UID、PID 及进程启动时间；不接受旧应用的状态报告冒充迁移完成。

首次读取不会启动第二张地图或停用旧应用。设置会迁移一次；之后不会用旧值覆盖用户在桥接中的修改。窗口就地缩放，正常切换和外观调节不增删虚拟显示。

## 兼容与检查

地图模块保留独立版 decoder-only-7 的行为，脚本差异仅为显示所属包和报告标记。继续只管理本地 111 地图解码，主视频与手机端 UI 协议由 DiPlay 处理。

旧有 19 组桥接检查保留，新增地图生命周期 49 项、进程身份 6 项、会话证据 9 项、迁移边界及所有者匹配 26 项。安装及迁移的实际结果记录于工作区 inspection/2026-10-25/bridge-map-integration，不应将本地检查当作所有车型的实车验证。

两个前台服务使用不同通知编号；home_map 与 bridge 偏好分开保存。桥接原有自动进入、媒体按键和通话控制逻辑未重写。

## 回退地图

在桥接中关闭桌面地图，重新启用原独立浮窗应用并开启它，再重开一次 DiPlay 以恢复旧显示所有者。旧设置、独立版 APK 和原桥接安装包均保留；无需删除配对数据或更换原版 DiPlay。
