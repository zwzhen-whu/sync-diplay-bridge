# 0.1.16 CarPlay 通话仪表显示

2026-10-22，versionCode 17。独立桥接新增默认关闭的通话显示开关，保留道路提示语清理、全部路名及蓝牙媒体/通话恢复设置。

## 输入和输出

读取当前 DiPlay UID、标签、进程和会话的完整实时 `0x4155` 日志帧。参数 0 为号码、1 为名称、2 为状态、4 为通话标识。依据官方 DiPlay v0.2.19 源码及本车测试数据实现；结束状态 0 在当前日志中格式化为 `""`，已兼容。开启前的历史通话不重放。来电等待优先于接通、保持及拨号；重复更新保留计时起点。通话不使用导航的 15 秒过期规则。

从本车电话应用及 android.car 框架代码核对：拨号显示状态 2、来电 6、接通 3、保持 16；原车蓝牙未连接空闲状态 7。辅助组件仅允许以下仪表显示属性：

| 属性 | 用途 |
| --- | --- |
| 554699825 | 姓名、号码，原生 `SignalID:0x50` 格式，保留 `BTDevie_Index` 等原字段拼写 |
| 557845523 | 通话秒数 |
| 557845524 | 仪表蓝牙连接显示 |
| 557845525 | 设备序号 |
| 557845528 | 电话显示状态 |

不写音频、麦克风、音量、隐私模式或电话控制属性。不实现联系人列表、照片、完整画面镜像或方向盘接听/挂断转发。姓名/号码去除协议分隔符、控制符及不可见格式符，分别限制 32/48 个完整 Unicode 码点；这是适配的保守上限，不是实测硬件最大长度。

## 连接与清理

仅连接本机 `127.0.0.1:5555`，使用车机已存在的 ADB 和 `su 0`。如 ADB 要求认证即停止，不复制私钥、不开启调试或修改系统权限。通过 `peekService` 获取已运行的原车服务，并核对电话属性配置与类型。

电话属性不能回读，因此清理按原车蓝牙断开后的空闲流程进行，不能声称恢复了不可读取的旧值。辅助组件只清除桥接已经接管的显示；HFP 重新连接后让出显示，避免覆盖原车电话卡片。独立监视线程在管道关闭、DiPlay 进程消失或超过 6 秒无心跳时清理。桥接在写入前保存一个布尔恢复标志，用于辅助组件异常退出后重试；不持久保存姓名、号码或通话标识。

## 验证

15 组回归通过，其中通话解析与格式 44 项、道路显示 161 项、蓝牙控制 106 项检查。原签名 APK 构建完成，实车辅助组件启动、心跳与退出输出 `READY / OK / OK`。用户随后反馈已手动安装测试成功；未逐项提供来电、中文姓名、计时和拔出清理的独立反馈，因此保留测试标签，其他车型和固件仍需核对。

原始测试通话、车辆诊断、签名密钥及本地检查文件不进入代码仓库。
