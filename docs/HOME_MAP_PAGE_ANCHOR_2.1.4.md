# 桌面所属页与二级页面修正 2.1.4

用户原车桌面默认位于第二页。旧跟随逻辑直接从保存的 x 减去桌面绝对 scrollX，导致在第二页放好的地图开启跟随后实际归到了第一页。现在保存开启跟随后的第一个有效桌面滚动位置，使用 `保存的 x − (当前 scrollX − 开启时 scrollX)` 定位。开启时地图不移动，切页和返回按这个基准跟随。

基准只在首次获得有效位置时写一次 `home_map.follow_scroll_origin`，不逐帧写盘。桥接重启和覆盖更新保留该值；关闭跟随移除基准，重新开启时可选择新的桌面所属页。编辑宽高和渐变不重选页面。

另外，显示判断从“桌面包名在前台”改为“系统解析得到的桌面主页 Activity 在前台”。实车的“更多服务”是 `MoreServerActivity`，“添加卡片”是 `AddCardActivity`，它们与主页同属 `com.baidu.xiaoduos.launcher`。新判断会隐藏这些二级页面上的地图，返回 `LauncherActivity` 后再显示。该逻辑不依赖跟随开关开启，也不要求为了隐藏二级页面额外授权无障碍服务。

使用原有 500 ms 桌面事件检查，不增加轮询。隐藏通过已有显示输出和窗口透明度处理，不释放虚拟显示，不改手机端视频协议。地图和通话运行脚本未修改。
