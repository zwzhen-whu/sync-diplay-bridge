# 0.1.15 去掉导航提示语，保留全部路名

2026-10-22，versionCode 16。用户停车后要求把第一条路选项改为仅去除提示语，保留 A 与 B 两条道路。

| 输入 | 保留原文 | 去掉导航提示语 |
| --- | --- | --- |
| `去往 A B` | `去往 A B` | `A B` |
| `去往 八一路 洪山侧路` | 原文 | `八一路 洪山侧路` |
| `现在 请 进入 八一路 洪山侧路` | 原文 | `八一路 洪山侧路` |
| `Main Street` | 原文 | `Main Street` |

处理只跳过开头连续、独立的已知提示词，使用原有“去往”“进入”“请”“现在”“右转”等集合和可解析的距离后提示。遇到第一个道路词后保留全部后缀，不再分割道路，也不删除后缀中的同名词。没有空格的 `进入八一路` 不猜测删除。只有提示语而没有道路时使用原缺失占位。

空白沿用既有规则：普通及 Unicode 空白归一为单个空格。两个实际路名之间的空格保留，不添加逗号。原来的 `first`、`comma` 设置在服务启动时持久迁移为 `without_prompts`，界面及发送端也兼容未迁移的旧值；原文设置继续保留。

十四组回归通过，道路显示 161 项检查涵盖用户的 A/B 样例、三条道路、第二条路改变后的发送、多词英文名、旧设置迁移、仅有提示语、源日志隔离及节流。蓝牙 106 项断言继续通过。原签名构建完成，安装与交付校验记录于 `inspection/2026-10-22/road-prompt-only/`。

用户本轮行车反馈为“原文还有，第一条路就没有了”。本次新模式保留全部路名，其仪表显示效果需另行核对；不能将显示规则调整称为已经修复底层乱码。
